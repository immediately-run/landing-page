# Your first app

Every TINKER app is a single file you can open, use, and take apart. This
walk-through goes from a blank file to a shareable app in under fifty lines —
no build step, no server, no sign-in.

## 1. Start with the shape

A TINKER app is a React component exported as the default of `App.tsx`. That
default export is the only contract: whatever it renders *is* your app.

```tsx
export default function App() {
  return <h1>Hello, tinker.</h1>;
}
```

Open the file and it runs. There is nothing else to wire up.

## 2. Add a live control

State is just React state. Anything you can `useState` becomes something a
visitor can poke at — and something *you* can rewire while it runs.

```tsx
import { useState } from 'react';

export default function App() {
  const [count, setCount] = useState(0);
  return (
    <button onClick={() => setCount((n) => n + 1)}>
      tinkered {count} times
    </button>
  );
}
```

## 3. Persist it

No backend required — the browser already has storage. Read it on load, write
it on change, and the app keeps a visitor's place across reloads.

```tsx
const [count, setCount] = useState(
  () => Number(localStorage.getItem('count')) || 0,
);
useEffect(() => {
  localStorage.setItem('count', String(count));
}, [count]);
```

## That's the whole loop

Open the file, use it, then **pop the hood** and rewire it while it runs. When
you want to share it, the file *is* the app — hand someone the link and they
can take it apart too.

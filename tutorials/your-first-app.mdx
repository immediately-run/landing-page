### Start from the template.

An app is a React and TypeScript repo with src/App.tsx as the entry point. Generate your own copy of the template on GitHub — the platform transpiles in the browser, so there is nothing to build and nothing to deploy.

<DeepLink label="Generate a repo from the template →" href="https://github.com/immediately-run/new-project-template/generate" />

### Make it yours in App.tsx.

The default export of src/App.tsx is what the platform renders. Edit it, import your global CSS from here, and keep one component per file. That is the whole contract.

<CodeBlock route="src/App.tsx">

```tsx
import './index.css';

export default function App() {
  return <h1>Hello from my first app.</h1>;
}
```

</CodeBlock>

<Checkpoint alt="editor with App.tsx open beside a live preview">
  Your headline renders in the preview pane, restyled in the brand canvas.
</Checkpoint>

### Push to GitHub.

Commit and push to main. Publishing is the push — there is no separate deploy, no pipeline to wait on. The platform loads the app straight from the repo on its next launch.

<CodeBlock route="terminal">

```tsx
git add -A
git commit -m "my first app"
git push origin main
```

</CodeBlock>

### Run it live.

Open the present route for your repo, branch, and entry file. Share that URL and anyone can run your app from source — the same way every app on the platform runs.
